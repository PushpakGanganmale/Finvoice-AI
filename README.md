### 1. Finvoice AI — AI-Powered Invoice Generator & Finance Assistant

An AI-powered invoicing application that converts natural-language input into structured invoices and helps manage invoice workflows.

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge)](https://finvoice-ai-arw2.vercel.app/)
[![GitHub](https://img.shields.io/badge/GitHub-Repository-black?style=for-the-badge&logo=github)](https://github.com/PushpakGanganmale/Finvoice-AI)

**Key Features**
- Generate structured invoices from natural-language descriptions using Groq LLM integration.
- Create, view, update, and manage invoices.
- Track invoice payment statuses, including paid, unpaid, and overdue.
- Generate and download invoice PDFs.
- Manage payment reminders and view revenue insights.
- Secure API endpoints using JWT authentication.
- Automated testing with Jest and CI workflows using GitHub Actions.

**Technology Stack**

`React` `JavaScript` `Vite` `Tailwind CSS` `Node.js` `Express.js` `MongoDB` `Groq API` `JWT` `Jest` `GitHub Actions` `Vercel`

### 2. ResumeGenius — AI-Powered Resume Builder

An AI-powered resume builder that helps users create and manage professional resumes with AI-generated content and live previews.

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge)](https://ai-resume-builder-frontend-g5gs.onrender.com/)
[![GitHub](https://img.shields.io/badge/GitHub-Repository-black?style=for-the-badge&logo=github)](https://github.com/PushpakGanganmale/ai_resume_builder)

**Key Features**
- Generate professional resume summaries and content using AI.
- Create and manage work experience, education, projects, and skills.
- Multiple resume templates with live previews.
- Backend APIs for resume creation, updates, and retrieval.
- JWT authentication with password hashing using bcrypt.
- Server-side PDF generation and download.
- Responsive interface for desktop and mobile devices.

**Technology Stack**

`React` `JavaScript` `Tailwind CSS` `Node.js` `Express.js` `MongoDB` `Groq API` `JWT` `bcrypt` `REST APIs`
